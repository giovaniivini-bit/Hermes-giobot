# ASCII Art and Video

This skill covers the creation of ASCII art and animated ASCII video from various inputs.

## ASCII Art

See the `ascii-art` skill for static ASCII art generation using tools like pyfiglet, cowsay, boxes, and image-to-ASCII conversion.

## ASCII Video

See the `ascii-video` skill for converting video/audio to colored ASCII MP4/GIF, including audio-reactive visuals and generative animations.
